PlantPulse

A DIY plant bioelectrical sonification system. PlantPulse reads microvolt-level electrical signals from plant leaves and transforms them into generative ambient music in real-time.

How it works

Soft alligator clips attach to a plant leaf, picking up tiny bioelectrical fluctuations. An ADS1115 16-bit ADC digitizes these signals, and an ESP32 microcontroller streams the raw voltage readings via MQTT. This browser dashboard visualizes the signal and maps it to music using the Web Audio API.

The music

Four instrument layers respond to different aspects of the plant's electrical activity:

Bass — deep drone following the smoothed signal drift
Melody — note selection driven by raw voltage, rhythm set by the plant's natural oscillation tempo
Arpeggio — broken chord patterns that activate when the plant is electrically active
Chimes — sparkly accents triggered by sudden signal spikes

Hardware

ESP32-WROOM-32D, ADS1115 ADC, soft alligator clips. Total cost ~$15. Full build instructions on GitHub.
